# Vault daily

Scratch layer for the day. Promote lasting conclusions into `theses/` or `risk-journal/`.

- Call `daily_note` (optional `date=YYYY-MM-DD`, optional `append`).
- The tool creates the file on first touch with Watched / Theses / CT / Risk headings.
- Keep appends short. If the thought should survive the week, write a thesis or risk note instead.

Local files only. No cloud vault.
